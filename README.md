# Expense Tracker — Мобільний застосунок для контролю витрат

## Про проект
**Expense Tracker** — мобільний застосунок для Android, призначений для обліку особистих фінансів, контролю щоденних покупок і планування місячного бюджету.

## Галузь застосування
**Торгівля** — застосунок орієнтований на споживачів, які здійснюють щоденні покупки товарів і послуг та потребують зручного інструменту для фіксації витрат за категоріями і контролю власного бюджету.

## Основні функціональні можливості
- **Облік надходжень:** фіксація грошових надходжень із зазначенням суми, дати та джерела доходу.
- **Фіксація витрат за категоріями:** швидке додавання витрат із вибором категорії («Продукти», «Транспорт», «Житло», «Розваги» тощо).
- **Керування категоріями витрат:** створення, редагування та видалення власних категорій.
- **Розрахунок залишку на місяць:** автоматичне обчислення доступного залишку коштів на поточний місяць.
- **Розрахунок залишку на день:** розрахунок орієнтовного денного ліміту з урахуванням залишку коштів і кількості днів до кінця місяця.
- **Історія операцій:** перегляд, фільтрація та редагування списку надходжень і витрат за день чи місяць.

## Архітектура застосунку
Концептуальна архітектура складається з чотирьох основних компонентів:
1. **Мобільний додаток (UI)** — інтерфейс користувача (екрани додавання операцій, вибору категорій, відображення залишків).
2. **Бізнес-логіка** — обробка дій користувача, підрахунок балансу та розрахунок денного і місячного залишків.
3. **Локальна база даних** — збереження транзакцій, категорій та налаштувань бюджету на пристрої.
4. **Хмарне сховище** — резервне копіювання та синхронізація даних.
